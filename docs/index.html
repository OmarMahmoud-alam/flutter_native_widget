إزاي بتشتغل؟

الـ widget اللي على الشاشة الرئيسية مش بيرسمها الأبليكيشن بتاعك؛ بيرسمها الـ launcher على أندرويد و SpringBoard على iOS، وهما مابيقبلوش غير وصف للشكل بلغتهم. فـ Flutter مايقدرش يشتغل هناك. الباكدج بتخلّيك تكتب الوصف ده بـ Dart، وبتولّد منه الكود الـ native.

lib/widgets.dart

بتكتب @HomeScreenWidget بـ layout ثابت (const) وحقول للداتا المتغيرة.

→build_runner

Android

Kotlin providers + RemoteViews XML + drawables + الـ manifest.

iOS

SwiftUI + WidgetKit + App Intents جوه Widget Extension.

Dart

API typed: CounterWidget.save(count: 5)

Native بجد

مفيش صورة بتترسم وتتحط. النص والساعة والأزرار views حقيقية بتتظبط مع dark mode والحجم والـ RTL لوحدها.

بيشتغل والأبليكيشن مقفول

الأزرار، الـ timeline، الساعة، والتحميل من النت كلهم بيحصلوا من غير ما Flutter يصحى.

مكان واحد للكود

الـ widget مكتوبة مرة واحدة. غيّرها وشغّل build_runner والمنصتين يتحدّثوا.

اكتب الـ widget

في أي ملف تحت lib/. الـ {count} في النص بتتبدّل بقيمة الحقل.

import 'package:flutter_native_widget/flutter_native_widget.dart';

part 'widgets.fnw.dart';

@HomeScreenWidget(
  displayName: 'Counter',
  fields: [NWField.integer('count')],
  layout: NWColumn(children: [
    NWText('{count}', style: NWTextStyle(size: 44)),
    NWRow(spacing: 12, children: [
      NWButton(action: NWAction.decrement('count', min: 0), child: NWText('−')),
      NWButton(action: NWAction.increment('count'), child: NWText('+')),
    ]),
  ]),
)
class Counter {}

المرجع

    
الـ layout عبارة عن شجرة const من عناصر NW*. القيم اللي بتتغير بتيجي من الحقول: {key} جوه النص، أو باراميتر field:. المرجع الكامل في pub.dev.


    
العناصر

    

      

        
العنصربيعمل إيه

        
NWColumn, NWRowيرصّوا العناصر؛ mainAxisAlignment و crossAxisAlignment و spacing. الصفوف بتتبع RTL.

        
NWStackعناصر فوق بعض.

        
NWBoxمقاس، padding، color أو gradient، border، radius، expand.

        
NWSpacerياخد المساحة الفاضية.

        
NWText / NWRichTextنص فيه {field}، أو أجزاء NWSpan لكل واحد شكله.

        
NWImageصورة من حقل image (مثلًا Flutter widget مترسومة).

        
NWIconMaterial icon على أندرويد، والـ SF Symbol المقابل على iOS.

        
NWProgressProgress من حقل رقمي بين 0 و max؛ .circular بيرسم حلقة.

        
NWClock / NWAnalogClockساعة digital أو analog بيحدّثها النظام.

        
NWDateTextتاريخ النهارده أو تاريخ من حقل، بـ pattern.

        
NWTimerعدّاد حي لحد (أو من) حقل dateTime، بيتحرك كل ثانية.

        
NWButtonيخلّي العنصر يتداس بـ NWAction.

        
NWIfيعرض child أو orElse حسب NWCondition.

        
NWRepeat / NWListيكرّر عنصر؛ # في المفاتيح بتبقى رقم العنصر. NWList بتعمل scroll على Android 12+.

الحدود

    
دي حدود المنصة نفسها، وأي باكدج تانية (أو كود native مكتوب بالإيد) عندها نفس الحدود.

    

      
✕
مفيش أنيميشن حر. لا حاجة بتلف ولا بتنبض. البديل: timeline بصور مختلفة.

      
✕
مفيش تحديث كل ثانية غير للساعة (NWClock) والعدّاد (NWTimer).

      
✕
مفيش كتابة نص ولا gestures غير الضغطة. البديل: زرار يفتح الأبليكيشن.

      
✕
مفيش scroll على iOS. البديل: صفحات بأزرار التالي والسابق.

      
!
iOS بيدّي ميزانية تحديثات (~40–70 في اليوم). استخدم timeline بدل التحديثات الكتير.

      
!
الـ layout لازم يبقى const لأن الـ generator بيقراه وقت الـ build. استخدم NWIf و NWRepeat بدل if و for.

    


    
أعمل الحتة دي إزاي؟


الحتة دي بتتغير كل ثانية أو دقيقة؟
├── أيوه، وهي ساعة أو تاريخ أو عدّاد  ← NWClock / NWAnalogClock / NWDateText / NWTimer
├── أيوه، وهي حاجة تانية             ← مش هينفع؛ استخدم timeline كل دقيقة
└── لأ
    ├── بتتغير في مواعيد معروفة       ← Timeline
    ├── بتتغير لما المستخدم يدوس      ← NWAction (native) أو ‎@WidgetCallback (Dart)
    ├── جاية من النت                  ← NWRefresh
    └── بتتغير لما الأبليكيشن يفتح    ← <Name>Widget.save(...)

الـ DSL يقدر يرسمها؟
├── أيوه ← native (أخف، وبتتظبط مع dark mode والحجم)
└── لأ   ← NWField.image + render<Field>() بأي Flutter widget
